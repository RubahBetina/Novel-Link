
# 📚 NovelLink - Web Platform & Supabase Setup Guide

Repositori ini berisi kode frontend untuk **NovelLink**, sebuah platform web dinamis untuk menampilkan koleksi novel *ongoing* maupun *completed* yang terhubung langsung dengan backend **Supabase**.

---

## 🛠️ Konfigurasi Database Supabase

Untuk menjalankan aplikasi ini dengan sempurna, kamu perlu membuat beberapa tabel di database Supabase kamu.

Masuk ke dashboard Supabase kamu, buka menu **SQL Editor**, lalu jalankan perintah SQL berikut untuk membuat tabel-tabel yang dibutuhkan:

### 1. Tabel `settings` (Pengaturan Website)

Tabel ini digunakan untuk menyimpan informasi umum situs seperti Judul, Logo, Teks Popup/Banner, dan Peringatan Hak Cipta.

```sql
create table settings (
  id bigint generated by default as identity primary key,
  site_title text,
  logo_url text,
  popup_text text,
  disclaimer_text text,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

```

### 2. Tabel `social_links` (Media Sosial)

Tabel ini digunakan untuk menampilkan tombol tautan media sosial resmi. *(Pastikan menggunakan kolom `platform` sesuai dengan struktur terbaru).*

```sql
create table social_links (
  id bigint generated by default as identity primary key,
  platform text not null,
  url text not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

```

### 3. Tabel `novel` (Koleksi Novel)

Tabel ini menyimpan daftar novel, lengkap dengan status (*ongoing* / *completed*), genre, platform/aplikasi baca, blurb, dan link baca.

```sql
create table novel (
  id bigint generated by default as identity primary key,
  title text not null,
  genre text,
  aplikasi text,
  description text,
  link text,
  cover_url text,
  status text, -- contoh: 'ongoing' atau 'completed'
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

```

---

## 🔑 Konfigurasi Kunci Supabase

Setelah tabel dibuat, pastikan kamu memasukkan kredensial Supabase kamu di bagian inisialisasi JavaScript pada file utama website (`index.html`):

```javascript
const SUPABASE_URL = 'URL_SUPABASE_KAMU_DI_SINI';
const SUPABASE_ANON_KEY = 'ANON_KEY_SUPABASE_KAMU_DI_SINI';

```

## 🚀 Cara Menjalankan Proyek

1. Clone repository ini ke komputer lokal kamu:
```bash
git clone https://github.com/username/novellink.git

```


2. Buka folder proyek.
3. Jalankan file `index.html` menggunakan browser atau gunakan ekstensi seperti **Live Server** di Visual Studio Code.
